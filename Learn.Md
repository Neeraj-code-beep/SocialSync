Route files :- These files define all the available routes/endpoints of the application. Basically, they tell which URL will trigger which functionality or API.
Controller files :- These files contain the actual logic behind the routes and APIs. They handle what should happen when a route is called, like fetching data, saving data, updating records, deleting records, etc.
